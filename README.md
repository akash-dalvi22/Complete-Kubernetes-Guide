# 🚀 Kubernetes Zero to Hero

A complete **hands-on Kubernetes learning repository** for students, freshers, and working professionals.

## 📌 What you’ll learn
- Kubernetes fundamentals & architecture
- Installing Kubernetes (Minikube, Kind)
- Core resources: Pods, Deployments, Services
- Networking, Storage, Security
- Helm, HPA, StatefulSets
- Production best practices
- Real-world deployment projects
- Kubernetes interview questions

## 🧑‍🎓 Who is this for?
- Students learning DevOps
- Freshers preparing for interviews
- Working professionals switching to DevOps
- Anyone who wants **practical Kubernetes knowledge**

## 🛠 Prerequisites
- Basic Linux commands
- Docker fundamentals
- YAML basics

## 🗂 Repository Structure
Each folder is a step-by-step guide with theory + hands-on YAML examples.

## ⭐ How to use this repo
1. Start from `00-introduction`
2. Follow folders in order
3. Practice YAML files in your local cluster
4. Deploy real-world apps
5. Revise interview questions
